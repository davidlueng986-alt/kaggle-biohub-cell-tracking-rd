Official semantics confirmed by code-read (not just behavior):
`extract_divisions` windows each `dividing_nodes()` (= **out-degree == 2 exactly**) node as
parent(s) → divider → children → grandchildren; `match_divisions` rematches the **full**
pred graph against **each GT window independently** with the same per-timepoint `1/(1+d)`
optimal assignment as the edge metric (S11); `_matched_division_nodes` needs a matched
parent side AND ≥2 non-empty daughter lineages (child + successors each); `_is_strongly_connected_division`
needs fork-or-predecessor parent anchor + bipartite ≥2 GT-lineages→distinct-pred-branches;
`_branch_component_evidence` gives **direct-child precedence** (matched child pins its branch;
grandchildren are fallback only when the child is unmatched) with **unanimous-grandchild**
fallback (0 or ≥2 components → no evidence, never a picked one) and **sole-parent**
malformed rejection; `_pred_division_fork_sets` poisons a fork over **ALL** child branches
(S5) and marks evaluable forks (matched to GT node with out-degree ≥ 1); final
`fp_forks = (considered | evaluable | invalid) − tp_forks` as a set union (S7), paired by
maximum-cardinality bipartite (one fork per GT division). Pred forks are out-degree ≥ 2
(multiedge-counted); the `+−1tp` late-fork figure in `metrics.md` is normative (S12).
